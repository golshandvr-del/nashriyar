# نشریار — سامانهٔ جامع نشریات دانشجویی

> سامانه‌ای یکپارچه برای مدیریت، پایش، انتشار و فروش نسخه‌های دیجیتال نشریات دانشجویی دانشگاه.

## وضعیت پروژه

🟢 **نسخهٔ ۱٫۰٫۰ — آمادهٔ استقرار.** فازهای ۰ تا ۱۰ نقشهٔ راه پیاده‌سازی و آزموده شده‌اند؛ فاز ۱۱ (استقرار روی هاست
و دامنهٔ شخصی) با Docker و راهنمای کامل [OPERATIONS](./docs/OPERATIONS.md) آماده است و فاز ۱۲ (اپ اندروید و حالت‌های
پیشرفتهٔ ثبت‌نام) برای بعد از نسخهٔ اولیه برنامه‌ریزی شده است. جزئیات در [نقشهٔ راه](./ROADMAP.md) و
[تاریخچهٔ تغییرات](./CHANGELOG.md).

## اصول کلیدی

- 🚫 **بدون فالوورشمار و لایک عمومی** — فقط مسئول نشریات آمار فالوور را می‌بیند.
- 🔗 **هر پست یک منبع دارد** — بخش مشخصی از فهرست یک شمارهٔ مشخص.
- 💬 **نظرها پیش از نمایش توسط تیم تأیید می‌شوند** و فیلتر خودکار واژه‌های نامناسب دارند.
- 💳 **بدون درگاه پرداخت** — پرداخت حضوری/کارت‌به‌کارت؛ دسترسی دیجیتال با **کد یک‌بارمصرف ۲۴ ساعته** (هش‌شده).
- 🔒 **نسخهٔ دیجیتال غیرقابل دانلود** — تصاویر امضاشدهٔ کوتاه‌مدت، canvas و واترمارک قابل ردیابی.
- 🧠 **هوشمندی بدون وابستگی** — موتور بینش قاعده‌محور همیشه فعال؛ AI اختیاری با سقف ماهانه و قطع‌کنندهٔ مدار.
- 🔐 **امنیت** — نشست httpOnly، CSRF، محدودیت تلاش ورود، RBAC، CSP سخت‌گیرانه، رمز دومرحله‌ای (TOTP) برای کارکنان.
- 🌗 **تم روشن و تیره**، فارسی و راست‌به‌چپ بومی، تقویم شمسی، PWA با حالت آفلاین، پالت فرمان `Ctrl+K` در پنل‌ها.
- 🏠 **قابل‌حمل** — یک کد برای Cloudflare (D1/R2) و سرور شخصی (Node + SQLite) بدون بازنویسی.

## پشتهٔ فناوری

TypeScript · Hono · SQLite (`node:sqlite` / Cloudflare D1) · React 19 + React Router 7 · Vite · Tailwind CSS 4 ·
Apache ECharts · pdf.js · Vazirmatn (محلی، بدون CDN) · GitHub Actions · Docker + Nginx + Certbot

## شروع سریع

پیش‌نیاز: Node.js ۲۲ یا جدیدتر.

```bash
npm install
npm run build                 # فرانت (dist/) + سرور (server-dist/node.mjs)
npm run seed                  # پایگاه دادهٔ نمونه در data/ (همهٔ داده‌های قبلی پاک می‌شود)
npm start                     # http://localhost:3000
```

حساب‌های نمایشی پس از seed:

| نقش | نام کاربری | رمز |
|---|---|---|
| سوپرادمین | `admin` | `admin1234` |
| مسئول نشریات | `officer` | `officer1234` |
| مدیرمسئول نمونه | `pub1-director` | `team1234` |
| دانشجو | `40012345` | `student1234` |
| ناظر دانشکده / تحلیلگر | `supervisor` / `analyst` | `super1234` / `analyst1234` |

> در محیط واقعی seed اجرا نکنید؛ سوپرادمین را با `node server-dist/node.mjs --create-admin admin` بسازید.

### دستورهای مفید

| دستور | کار |
|---|---|
| `npm run typecheck` | بررسی نوع TypeScript |
| `npm test` | آزمون‌های سرتاسری (نیاز به `npm run build`) |
| `npm run backup` | پشتیبان فوری پایگاه داده در `data/backups/` |
| `node server-dist/node.mjs --migrate` | اعمال مایگریشن‌ها |
| `node server-dist/node.mjs --create-admin [username]` | ساخت یا بازنشانی سوپرادمین (رمز موقت + پاک کردن 2FA) |
| `docker compose up -d` | استقرار تولید با Nginx و TLS — ر.ک. [OPERATIONS](./docs/OPERATIONS.md) |
| `npm run deploy:cf` | استقرار روی Cloudflare Pages |

## ساختار مخزن

```
src/
  server/      بک‌اند Hono: routes/ (public, auth, me, team, admin, analytics, media)، lib/، adapters/، insights، ai
  entry/       نقطه‌های ورود node.ts و cloudflare
  web/         فرانت React: public/، team/، admin/، components/، lib/
  shared/      کد مشترک (اعداد و تاریخ شمسی، نرمال‌سازی فارسی، پیش‌بینی خطی)
migrations/    مایگریشن‌های SQL (0001_init، 0002_totp)
tests/         smoke و admin-writes ؛ scripts/test-e2e.mjs اجراکنندهٔ آزمون‌ها
deploy/        پیکربندی Nginx ؛ Dockerfile و docker-compose.yml در ریشه
docs/          مستندات طراحی و عملیات
```
