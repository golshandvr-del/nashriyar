# نشریار — سامانهٔ جامع نشریات دانشجویی

> سامانه‌ای یکپارچه برای مدیریت، پایش، انتشار و فروش نسخه‌های دیجیتال نشریات دانشجویی دانشگاه.
> «نشریار» نام کاری پروژه است.

## وضعیت پروژه

🟡 **مرحلهٔ طراحی و برنامه‌ریزی تکمیل شد** — آمادهٔ شروع فاز ۰ (پایه و زیرساخت).
جزئیات کامل در [**نقشهٔ راه**](./ROADMAP.md).

## سه بخش اصلی

| بخش | کاربر | امکانات کلیدی |
|---|---|---|
| 🛡️ **پنل مدیریت جامع** | مسئول نشریات دانشگاه | تعریف نشریات و تیم‌ها، برد زندهٔ تولید، آمار بازه‌ای و مقایسه‌ای، رتبه‌بندی، بازدهی مدیرمسئول‌ها، فاصلهٔ انتشار، آمار اکسپلور و فروش، بینش‌های هوشمند، ممیزی |
| ✍️ **پنل تیم نشریه** | مدیرمسئول، سردبیر، صاحب امتیاز | اعضا، تعریف شماره، فهرست مطالب، تقسیم کار، تایم‌لاین/چک‌لیست پیشرفت، بارگذاری PDF/صوت/ویدیو/عکس، پست‌های اکسپلور با منبع، تأیید کامنت، ساخت کد فروش |
| 📚 **پیشخوان عمومی** | همهٔ بازدیدکنندگان و دانشجویان | مرور و جست‌وجو شبیه طاقچه/کتابراه، دسته‌بندی موضوعی و رشته‌ای، صفحهٔ نشریه با دو تب (پست‌ها/نشریات)، اکسپلور آرام بدون اعداد رقابتی، کتابخانهٔ شخصی، کتاب‌خوان امن |

## اصول کلیدی

- 🚫 **بدون فالوورشمار و لایک عمومی** — فقط مسئول نشریات آمار فالوور را می‌بیند.
- 🔗 **هر پست یک منبع دارد** — بخش مشخصی از فهرست یک شمارهٔ مشخص.
- 💬 **کامنت‌ها پیش از نمایش توسط تیم تأیید می‌شوند.**
- 💳 **بدون درگاه پرداخت** — پرداخت حضوری/کارت‌به‌کارت؛ دسترسی دیجیتال با **کد یک‌بارمصرف ۲۴ ساعته**.
- 🔒 **نسخهٔ دیجیتال غیرقابل دانلود** با واترمارک قابل ردیابی و بازدارنده‌های اسکرین‌شات.
- 🧠 **هوشمندی بدون وابستگی** — موتور بینش قاعده‌محور همیشه فعال؛ هوش مصنوعی صرفاً افزونهٔ اختیاری.
- 🌗 **تم روشن و تیره**، فارسی و راست‌به‌چپ بومی، تقویم شمسی.
- 🏠 **قابل‌حمل** — پیش‌نمایش روی لینک موقت، استقرار نهایی روی هاست و دامنهٔ شخصی بدون بازنویسی.

## پشتهٔ فناوری (برنامه‌ریزی‌شده)

TypeScript · Hono · Drizzle ORM (SQLite / D1، مسیر PostgreSQL) · React + Vite · Tailwind CSS ·
Apache ECharts · pdf.js · Vitest · Playwright · GitHub Actions ·
Cloudflare Pages (پیش‌نمایش) → Docker + Nginx روی هاست شخصی (تولید)
