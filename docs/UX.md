# تجربهٔ کاربری، سامانهٔ طراحی و فهرست صفحات

## ۱. اصول رابط کاربری

1. **فارسی‌محور واقعی:** `dir="rtl"`، فونت وزیرمتن، اعداد فارسی در نمایش (ورود هر دو نوع عدد پذیرفته
   و نرمال می‌شود)، تقویم شمسی در همهٔ تاریخ‌ها و بازه‌گزین‌ها، نیم‌فاصلهٔ درست در متن‌ها.
2. **تم روشن و تیره** با سه حالت «روشن / تیره / مطابق سیستم»؛ انتخاب کاربر در حساب و `localStorage`
   ذخیره می‌شود؛ بدون «چشمک» هنگام بارگذاری (اسکریپت کوچک پیش از رندر). نمودارها، کتاب‌خوان و
   تصاویر بندانگشتی هم با تم هماهنگ می‌شوند.
3. **سه شخصیت بصری با یک زبان طراحی:**
   - پیشخوان عمومی: گرم، تصویری، کارت‌های جلد بزرگ، موبایل‌محور با نوار پایین (Bottom Nav).
   - پنل تیم: کاربردی، متمرکز بر کار، راهنمای گام‌به‌گام برای کاربران تازه‌کار.
   - پنل مسئول: داده‌محور، چگال، دسکتاپ‌محور با نوار کناری، کارت‌های KPI و نمودار.
4. **دسترس‌پذیری:** تضاد رنگ WCAG AA در هر دو تم، ناوبری کامل با صفحه‌کلید، برچسب‌های ARIA،
   متن جایگزین تصاویر (تیم هنگام پست گذاشتن وارد می‌کند)، احترام به `prefers-reduced-motion`.
5. **کارایی:** اسکلت بارگذاری (Skeleton)، تصاویر تنبل و واکنش‌گرا، تقسیم کد برای هر بخش
   (عموم هرگز کد داشبورد مسئول را دانلود نمی‌کند)، هدف LCP زیر ۲ ثانیه روی ۴G.
6. **حالت‌های خالی آموزنده:** هر صفحهٔ خالی توضیح می‌دهد چه کاری باید کرد (مثلاً «هنوز شماره‌ای
   تعریف نکرده‌اید — شمارهٔ اول را بسازید»).
7. **بدون اعداد رقابتی در فضای عمومی:** هیچ لایک‌شمار، فالوورشمار یا بازدیدشمار عمومی.

## ۲. توکن‌های طراحی

- رنگ‌ها به‌صورت متغیرهای CSS معنایی: `--bg`, `--surface`, `--surface-2`, `--text`, `--text-muted`,
  `--primary`, `--accent`, `--success`, `--warning`, `--danger`, `--border`؛ مقدار جدا برای `.dark`.
- رنگ اصلی پیشنهادی: آبی-فیروزه‌ای عمیق (حس علمی و آرام) با رنگ مکمل کهربایی برای تأکید.
- هر نشریه یک **رنگ شاخص** دارد که در صفحهٔ آن به‌صورت ظریف (هدر، دکمه‌ها) اعمال می‌شود.
- مقیاس فاصله ۴ پیکسلی، شعاع گوشه‌ها ۸/۱۲/۲۰، سایه‌های نرم در روشن و حاشیه‌های ظریف در تیره.
- آیکن‌ها: مجموعهٔ Lucide (bundle‌شده، SVG درون‌خطی).

## ۳. پیشخوان عمومی (الهام از طاقچه/کتابراه + اینستاگرام آرام)

| مسیر | صفحه | محتوا |
|---|---|---|
| `/` | خانه | بنر/قفسه‌های ویژه، تازه‌ترین شماره‌ها، «ادامهٔ مطالعه» (واردشده)، قفسه بر اساس دسته‌ها، نشریات دانشکده‌ها، فراخوان‌های همکاری |
| `/explore` | اکسپلور | شبکهٔ تصاویر پست‌ها (Masonry)، فیلتر دسته/دانشکده، بخش «از نشریاتی که دنبال می‌کنید» (واردشده)، استوری‌ها در بالای صفحه |
| `/p/:postId` | پست | تصویر(ها)، کپشن، **کارت منبع**: «از بخش X در شمارهٔ Y نشریهٔ Z» با دکمهٔ «خواندن کامل»، کامنت‌های تأییدشده، ذخیره، گزارش |
| `/categories` و `/c/:slug` | دسته‌بندی‌ها | درخت موضوعی، رشته‌ای، قالب (متنی/صوتی/تصویری) |
| `/faculties/:id` | دانشکده | انجمن‌ها و نشریات آن دانشکده |
| `/search` | جست‌وجو | نتایج نشریات، شماره‌ها، مطالب فهرست، پست‌ها، افراد (نویسندگان)؛ فیلترهای جانبی |
| `/:pubSlug` | **صفحهٔ نشریه** | هدر (لوگو، نام، انجمن صاحب امتیاز، دانشکده، دکمهٔ دنبال کردن **بدون عدد**)، هایلایت‌ها، دو تب: **«پست‌ها»** (شبکهٔ سه‌ستونی) و **«نشریات دیجیتال»** (قفسهٔ جلدها شبیه کتاب‌خوان)؛ تب فرعی «دربارهٔ ما و تیم» و «راه‌های خرید» |
| `/:pubSlug/:issueNo` | **صفحهٔ شماره** | جلد، عنوان، تاریخ، صفحات، دسته‌ها، کلیدواژه‌ها، **فهرست مطالب با نام نویسندگان**، رسانه‌های پیوست (پادکست، کلیپ، گالری)، دکمهٔ «خواندن» / «پیش‌نمایش رایگان» / «راه‌های خرید» (نمایش شناسه/شماره تماس تیم) / «ثبت کد خرید» |
| `/read/:issueId` | **کتاب‌خوان امن** | تمام‌صفحه، ورق زدن (لمس/کلید)، حالت تک/دوصفحه‌ای، بزرگ‌نمایی، فهرست، نشان‌گذاری، یادداشت خصوصی، حالت شب، نوار پیشرفت؛ واترمارک پویا |
| `/listen/:assetId` | پخش‌کننده | پادکست با سرعت پخش و ادامه از آخرین نقطه |
| `/library` | کتابخانهٔ من | قفسهٔ خریداری‌شده‌ها و رایگان‌های افزوده، در حال مطالعه، تمام‌شده، ذخیره‌شده‌ها |
| `/redeem` | **ثبت کد خرید** | یک فیلد بزرگ کد (با قالب‌دهی خودکار و پذیرش اعداد فارسی)، پیش‌نمایش «این کد مربوط به شمارهٔ X است» و دکمهٔ تأیید، سپس انیمیشن افزودن به کتابخانه |
| `/following` | دنبال‌شده‌ها | فهرست نشریات دنبال‌شده و پست‌های تازه (فقط برای خود کاربر) |
| `/notifications` | اعلان‌ها | پست/شمارهٔ جدید نشریات دنبال‌شده، تأیید/رد کامنت، افزوده شدن به کتابخانه |
| `/login`, `/register` | ورود و ثبت‌نام | شماره دانشجویی + رمز؛ پذیرش قوانین (شامل توضیح واترمارک) |
| `/me/settings` | تنظیمات حساب | تم، تغییر رمز، نشست‌های فعال، حذف حساب |
| `/verify/:code` | استعلام گواهی همکاری *(پیشنهادی)* | تأیید اصالت گواهی |

ناوبری پایین در موبایل: خانه · اکسپلور · جست‌وجو · کتابخانه · حساب.

## ۴. پنل تیم نشریه (`/team`)

| مسیر | صفحه | محتوا |
|---|---|---|
| `/team` | انتخاب نشریه | اگر کاربر در چند نشریه نقش دارد |
| `/team/:pub` | پیشخوان تیم | شمارهٔ جاری و پیشرفت، کارهای عقب‌افتاده، کامنت‌های در انتظار، اطلاعیه‌های مسئول، مهلت‌ها |
| `/team/:pub/members` | اعضا | افزودن/ویرایش/غیرفعال‌سازی اعضا، نقش‌های پیش‌فرض، تاریخ پیوستن |
| `/team/:pub/issues` | شماره‌ها | فهرست شماره‌ها با وضعیت |
| `/team/:pub/issues/new` | **جادوگر شمارهٔ جدید** | ۱) نام و مشخصات و دسته/کلیدواژه ← ۲) فهرست مطالب (درختی، کشیدن و رها کردن، چسباندن فهرست متنی و تبدیل خودکار به آیتم‌ها) ← ۳) اعضای فعال و نقش‌ها ← ۴) تخصیص نویسنده/ویراستار به هر بخش (ماتریس بخش × فرد) ← ۵) انتخاب نمای پیشرفت (تایم‌لاین/چک‌لیست/کانبان) و مراحل و مهلت‌ها |
| `/team/:pub/issues/:id` | **اتاق کار شماره** | تب‌ها: نمای کلی · فهرست و تخصیص · **پیشرفت** (نوار تایم‌لاین مراحل + تیک بخش‌ها) · رسانه و نسخه · فروش و کدها · پیش‌نمایش عمومی |
| `/team/:pub/issues/:id/publish` | انتشار | بارگذاری PDF (تبدیل در مرورگر با نوار پیشرفت)، جلد، تعداد صفحات خودکار، قیمت‌گذاری، صفحات پیش‌نمایش رایگان، راه‌های خرید، زمان‌بندی انتشار، ارسال برای تأیید (اگر فعال) |
| `/team/:pub/posts` | پست‌ها و هایلایت‌ها | ساخت پست: آپلود عکس (برش ۱:۱/۴:۵، فشرده‌سازی)، کپشن، **انتخاب اجباری منبع: شماره ← بخش فهرست**، زمان‌بندی؛ مدیریت هایلایت‌ها و استوری‌ها |
| `/team/:pub/comments` | صف تأیید کامنت | تأیید/رد گروهی، دلیل رد، پاسخ تیم، علامت اسپم |
| `/team/:pub/sales` | فروش | ساخت کد تکی/دسته‌ای (نمایش یک‌باره + کپی + QR)، فهرست کدها با وضعیت، ابطال، ثبت فروش چاپی، مدیریت راه‌های تماس خرید |
| `/team/:pub/profile` | صفحهٔ نشریه | لوگو، جلد، رنگ شاخص، معرفی، دسته‌ها، رشته‌ها، کلیدواژه‌ها |
| `/team/:pub/recruit` | فراخوان همکاری *(پیشنهادی)* | |

### نمای پیشرفت (قلب پنل تیم)
- **تایم‌لاین:** نوار افقی مراحل (نویسندگی ← ویراستاری ← گرافیک ← صفحه‌آرایی ← بازبینی ← انتشار)؛
  هر مرحله سه حالت «در انتظار / در حال انجام / انجام‌شده» با تاریخ شروع/پایان خودکار؛ زیر مرحلهٔ
  نویسندگی و ویراستاری، تیک‌های تک‌تک بخش‌های فهرست با نام مسئول هر بخش.
- **چک‌لیست:** همان داده‌ها به شکل فهرست عمودی تیک‌خوردنی.
- **کانبان** *(پیشنهادی)*: ستون‌های وضعیت و کارت‌های بخش‌ها.
- هر تیک یک رویداد زمان‌دار ثبت می‌کند (پایهٔ آمار مدت مراحل)؛ برداشتن تیک هم ثبت می‌شود.

### داشبورد: الگوی بصری
- بالای صفحه: بازه‌گزین شمسی + دکمهٔ «مقایسه با…» + فیلترهای سراسری که در URL ذخیره می‌شوند
  (قابل اشتراک و بوکمارک).
- ردیف KPI: هر کارت عدد، تغییر درصدی با پیکان رنگی، اسپارک‌لاین.
- نمودارها: خطی (روند)، میله‌ای (مقایسهٔ دانشکده‌ها)، گانت (مراحل)، نقشهٔ حرارتی (روز × ساعت)،
  دونات (دسته‌ها)، پراکندگی (بازدهی مدیران)، قیف (اکسپلور ← خرید).

## ۶. ریزتعامل‌ها و جزئیات دلنشین

- انیمیشن نرم ورق خوردن در کتاب‌خوان؛ گذار صفحه با View Transitions API (در صورت پشتیبانی).
- پیش‌نمایش زندهٔ صفحهٔ عمومی هنگام ویرایش پروفایل نشریه یا ساخت پست.
- میانبرهای صفحه‌کلید در داشبوردها (`/` برای جست‌وجو، `Ctrl+K` پالت فرمان).
- اعلان‌های درون‌برنامه‌ای (Toast) فارسی، با امکان «بازگردانی» برای اقدامات قابل برگشت.
- نسخهٔ PWA قابل نصب روی گوشی با آیکن و صفحهٔ آغازین.
